## Описание курса
Репозиторий содержит материалы курса по Python, охватывающего:
- **Процедурное программирование**
- **Объектно-ориентированное программирование (ООП)**
- **Анализ данных** (с использованием библиотек типа Pandas, NumPy и др.)

Все задания и лабораторные работы решены и проверены. Каждая папка содержит:
- Решения задач
- Примеры кода
- Необходимые данные (если требуется)

---

## Структура репозитория
```
.
├── procedural_programming/  # Процедурное программирование
│   ├── task_1/              # Пример задания
│   │   ├── solution.py      # Решение
│   │  
│   └── ...
├── oop/                     # Объектно-ориентированное программирование
│   ├── lab_1/               # Лабораторная работа
│   │   ├── classes.py       # Классы и объекты
│   │   └── test.py          # Тесты
│   └── ...
├── data_analysis/           # Анализ данных
│   ├── project_1/           # Проект с анализом данных
│   │   ├── data.csv         # Исходные данные
│   │   ├── analysis.ipynb   # Jupyter Notebook
│   │  
│   └── ...
└── requirements.txt         # Зависимости для Python
```

---

## Требования
- Python 3.8+
- Установленные библиотеки из `requirements.txt`:
  ```bash
  pip install -r requirements.txt
  ```

---

## Как использовать
1. **Склонируйте репозиторий:**
   ```bash
   git clone https://github.com/ваш-репозиторий.git
   ```
2. **Запустите скрипты:**
   ```bash
   cd procedural_programming/task_1
   python solution.py
   ```
3. **Для анализа данных:**
   - Откройте Jupyter Notebook:
     ```bash
     jupyter notebook analysis.ipynb
     ```
